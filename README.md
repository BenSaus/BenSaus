## Ben Sauskojus

Software engineer in Montana currently at Linktree.

I like owning things end to end — the API, the interface in front of it, and the infrastructure underneath. My depth is on the backend: high-throughput data pipelines and the distributed systems around them. But I've shipped frontends, internal tools, serverless workflows, and games, and I do my best work when the problem doesn't stop at a layer boundary.

### What I work on

- **Backend and data.** Streaming pipelines that ingest and normalize large volumes of third-party data — streaming parsers, batched writes, and backpressure, so throughput doesn't come at the expense of the database behind it.
- **Distributed systems.** Locking, idempotency, and per-unit retry isolation across service instances, so scheduled work that runs everywhere still behaves like it ran once.
- **Full-stack product work.** REST and GraphQL APIs alongside the React and Vue frontends that consume them, plus the admin tooling that makes them operable.
- **Internal platforms.** Low-code tooling that lets non-engineers run processes that used to require an engineer — sandboxed analysis, automated code generation via AST rewriting, and workflow state machines.
- **Reliability.** Chasing down memory leaks, OOM crashes, and CPU saturation by correlating logs against metrics — and designing the fix before it turns into an incident.
- **Technical design.** Written proposals with explicit tradeoff analysis: sizing, failure modes, and alternatives compared before the first line of code gets written.
