## Ben Sauskojus

Backend engineer in Bozeman, MT, currently at Linktree.

I build high-throughput data pipelines and the distributed systems around them — backend work that has to move a lot of data on a schedule without falling over.

### What I work on

- **Streaming data pipelines.** Ingesting and normalizing large volumes of third-party data — streaming parsers, batched writes, and backpressure, so throughput doesn't come at the expense of the database behind it.
- **Distributed coordination.** Locking, idempotency, and per-unit retry isolation across service instances, so scheduled work that runs everywhere still behaves like it ran once.
- **Internal platforms.** Low-code tooling that lets non-engineers run processes that used to require an engineer — sandboxed analysis, automated code generation via AST rewriting, and workflow state machines.
- **Reliability and debugging.** Chasing down memory leaks, OOM crashes, and CPU saturation by correlating logs against metrics — and designing the fix before it turns into an incident.
- **Technical design.** Written proposals with explicit tradeoff analysis: sizing, failure modes, and alternatives compared before the first line of code gets written.
